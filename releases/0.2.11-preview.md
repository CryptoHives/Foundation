# CryptoHives Foundation 0.2.11-preview

*Released 2025-11-19 · tag `0.2.11.20784-preview` · first release*

The first published build. Two packages appear: `CryptoHives.Foundation.Memory` and
`CryptoHives.Foundation.Threading`.

## New: `CryptoHives.Foundation.Memory`

- `ArrayPoolBufferWriter<T>` — an `IBufferWriter<T>` that assembles a `ReadOnlySequence<T>` from
  pooled chunks, with `ArrayPoolBufferSegment<T>` and `ArrayPoolBufferSequence<T>` behind it.
- `ArrayPoolMemoryStream` — a `MemoryStream` backed by `ArrayPool<byte>` segments.
- `ReadOnlySequenceMemoryStream` — a read-only stream over an existing `ReadOnlySequence<byte>`.
- `ObjectOwner<T>` — a `readonly struct` RAII wrapper over `ObjectPool<T>`, plus `ObjectPools`.

## New: `CryptoHives.Foundation.Threading`

The pooled `IValueTaskSource<T>` foundation the whole package is built on, and the first three
primitives built on it:

- `AsyncLock`, `AsyncAutoResetEvent`, `AsyncManualResetEvent`
- `ManualResetValueTaskSource<T>`, `PooledManualResetValueTaskSource<T>`,
  `LocalManualResetValueTaskSource<T>`, `PooledValueTaskSourceObjectPolicy<T>`

The design goal from the start: return `ValueTask` rather than `Task`, and keep the uncontended path
free of heap allocation.

## Infrastructure

Azure Pipelines CI, the NuGet packaging pipeline, DocFX GitHub Pages, a Contributor Covenant code of
conduct, license scanning, and the first benchmark suite for the threading primitives.
