# CryptoHives Foundation 0.5.21-preview

*Released 2026-04-28 · tag `0.5.21.47953-preview`*

A refactoring release that gave the hash algorithms a common incremental core and pushed Arm64
coverage further.

## Cryptography — API

**`IIncrementalHash`** (#140) — a shared interface for hash cores, with BLAKE2b reimplemented as
the template for the pattern. This is what lets the MAC and KDF layers consume any hash uniformly.

## Cryptography — BLAKE3 restructure

`Blake3.Ssse3` became `Blake3State.Ssse3`, joined by `Blake3State` and `Blake3State.Xof` — the
state/algorithm split that the AVX2 and AVX-512 work in 0.6.51 later builds on.

## Cryptography — Arm64 and performance

- **`KeccakCoreState.Arm64`** — NEON acceleration for the Keccak permutation, benefiting SHA-3,
  SHAKE, cSHAKE, KMAC and TurboSHAKE at once
- **BLAKE2b/BLAKE2s** performance (#137), **Poly1305** performance, and **ARIA/Camellia**
  performance (#141)

## Cryptography — RNG

`RandomNumberGenerator` — a polyfill giving the older target frameworks the same API surface the
modern ones have (#135).

## Tests

Hash reference-implementation tests were refactored onto the algorithm registry (#142), so adding an
algorithm registers it for cross-validation rather than requiring a bespoke test.
