# CryptoHives Foundation 0.2.26-preview

*Released 2025-12-06 · tag `0.2.26.53860-preview`*

An allocation-focused release.

## Threading

- **A local cache for value task sources returned, and cancellation-token registrations became
  allocation-free** (#53). This is the pattern the package still uses: the first waiter on a
  primitive uses a source held locally on the instance, and only additional concurrent waiters go to
  the shared pool.
- `IGetPooledManualResetValueTaskSource<T>` was introduced to express that split, with
  `LocalManualResetValueTaskSource<T>` and `ValueTaskSourceObjectPool<T>` reworked around it.
- All three primitives — `AsyncLock`, `AsyncAutoResetEvent`, `AsyncManualResetEvent` — were updated
  to use it.

## Benchmarks and docs

Benchmarks for `AsyncManualResetEvent` (#55), and an impressum for the GitHub Pages site (#57).
