# CryptoHives Foundation 0.5.34-preview

*Released 2026-06-02 · tag `0.5.34.36706-preview`*

The last preview before 0.6. Focus: a convenient static API, and per-package documentation.

## Cryptography — static one-shot API (#157)

Every hash algorithm gained `HashData` / `TryHashData` static methods mirroring the BCL's
`SHA256.HashData` shape, backed by a new `HashAlgorithmPool` so the one-shot call reuses a pooled
instance instead of allocating one per call. Added across MD5, SHA-1, the SHA-2 family, RIPEMD-160,
and the regional hashes (Kupyna, LSH-256/512, SM3, Streebog, Whirlpool).

**`ReadOnlySequence<byte>` overloads** (#158) followed, so segmented buffers hash without being
flattened first.

## Cryptography — algorithms

- **ParallelHash** (#153), with documentation and test vectors
- **HMAC-SHA3-384** and **HMAC-SHA3-512**

## Documentation

**Per-package READMEs** (#154) — the packages stopped sharing one README and each got its own, which
is what NuGet.org now shows on each package page. `Threading`, `Threading.Analyzers` and
`Security.Cryptography` all gained substantial documents here.

## Build

NuGet packages are now tested before being pushed to the feed (#147) — the pack-then-test-against-the-pack
step that still runs in `.azurepipelines/nuget.yml`.
