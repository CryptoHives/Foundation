# CryptoHives Foundation 0.2.43-preview

*Released 2026-01-09 · tag `0.2.43.28223-preview`*

The threading package went from three primitives to seven.

## New async primitives (#59)

| Type | Purpose |
|---|---|
| `AsyncSemaphore` | counted async gate |
| `AsyncReaderWriterLock` | shared/exclusive async lock |
| `AsyncBarrier` | phased rendezvous with a post-phase action |
| `AsyncCountdownEvent` | wait for N signals |

All four are built on the same pooled `IValueTaskSource<T>` machinery as the existing `AsyncLock`,
`AsyncAutoResetEvent` and `AsyncManualResetEvent`, so they inherit the allocation behavior rather
than reimplementing it. Roughly 1,600 lines of new primitive code.

`AsyncLock` was reworked alongside them, and `ValueTaskSourceObjectPools` grew the per-type pools the
new primitives needed.
