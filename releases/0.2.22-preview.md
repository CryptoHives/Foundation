# CryptoHives Foundation 0.2.22-preview

*Released 2025-12-01 · tag `0.2.22.44919-preview`*

The release that made the threading primitives cancellable, and put the pool on a formal footing.

## Threading

- **Cancellation support across the async primitives** (#46), with the tests and benchmarks to
  match. `AsyncLock`, `AsyncAutoResetEvent` and `AsyncManualResetEvent` were substantially reworked.
- **The value-task-source pool became a real type.** `ValueTaskSourceObjectPool<T>` and
  `ValueTaskSourceObjectPools` replaced the ad-hoc `PooledEventsCommon` helper, which was deleted.
- **Object-pool leak detection** (#51, #52) — checks that a rented source is always returned, which
  is what keeps the allocation-free claim honest rather than aspirational.

## Memory

`ObjectOwner<T>` and `ObjectPools` picked up the same leak-checking discipline.

## Build

The signed build was repaired (#48), and more third-party async reference implementations were added
to the benchmark set (#49).
