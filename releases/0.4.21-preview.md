# CryptoHives Foundation 0.4.21-preview

*Released 2026-02-28 · tag `0.4.21.64110-preview`*

The cryptography package stopped being a hash library and became a full primitive suite —
roughly 11,000 new lines covering ciphers, MACs and key derivation.

## New: symmetric ciphers (#108)

Block ciphers and AEAD modes built on a common `SymmetricCipher` base that extends
`System.Security.Cryptography.SymmetricAlgorithm`, with an `ICipherTransform` /
`BlockCipherTransform` abstraction and an `IAeadCipher` interface for authenticated modes.

## New: message authentication codes (#109, #116)

- **HMAC** over a shared `HmacCore` — MD5, SHA-1, SHA-256, SHA-384, SHA-512 and SHA3-256 variants
- **AES-CMAC** and **AES-GMAC**
- **Poly1305**
- A common `IMac` interface across all of them

## New: key derivation functions

`HKDF`, `KBKDF`, `ConcatKDF` and `PBKDF2`.

## New: hardware capability detection

`SimdSupport` — the runtime feature probe that every accelerated implementation from here on
consults to pick its code path.

## Incremental hashing API (#113)

`AppendData` / `TryGetHashAndReset`, a zero-allocation incremental interface mirroring the BCL's
`IncrementalHash` shape.

**Bug fix:** `TryComputeHash` did not reset algorithm state after finalization (#114), so a second
call on the same instance could return a hash of the wrong accumulated input.

## Other

The GCM H-powers precompute was removed (#110), and cipher algorithm references were filled in
across the documentation (#112).
