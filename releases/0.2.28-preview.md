# CryptoHives Foundation 0.2.28-preview

*Released 2025-12-07 · tag `0.2.28.48077-preview`*

## New: `CryptoHives.Foundation.Threading.Analyzers`

A third package joins the suite (#60) — a Roslyn analyzer and code-fix provider for the `ValueTask`
contract, which is easy to violate and unforgiving when you do.

- `ValueTaskMisuseAnalyzer` and `ValueTaskMisuseCodeFixProvider` (~1,340 lines between them)
- `DiagnosticIds` and `DiagnosticDescriptors` establishing the `CHT0xx` rule family
- Roslyn analyzer release tracking (`AnalyzerReleases.Shipped.md` / `.Unshipped.md`)

The rules cover the mistakes that a pooled `IValueTaskSource` implementation punishes hardest:
awaiting a `ValueTask` twice, blocking on `.GetAwaiter().GetResult()`, reading `.Result` directly,
storing a `ValueTask` in a field, and dropping one unconsumed.

The analyzer NuGet build was fixed in the same release (#61).
