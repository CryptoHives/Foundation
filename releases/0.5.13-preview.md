# CryptoHives Foundation 0.5.13-preview

*Released 2026-04-02 · tag `0.5.13.21047-preview`*

Arm64 acceleration arrives, and `AsyncReaderWriterLock` gets a substantial rework.

## Cryptography — Arm64

- **NEON for AES** (#132) and **for the BLAKE algorithms** (#129)
- **`SHA256Core.Arm`** — ARM SHA-2 crypto extensions for SHA-224/256

`SimdSupport` grew the corresponding capability flags. Managed fallbacks keep results identical
where the hardware path is unavailable, which is the invariant the whole package rests on.

## Cryptography — algorithms

**Ascon, the regional ciphers and AES key wrap** (#120) — a large addition bringing ARIA, Camellia,
Kalyna, Kuznyechik, SEED and SM4 into the cipher set, plus `AesKeyWrapPad`.

## Threading — `AsyncReaderWriterLock`

- **Upgradeable reader support**, with the lock operations simplified around it (#124)
- **An `Interlocked` fast path** for acquiring a reader or writer lock (#122), so the uncontended
  case never touches the internal lock
- **`Internal/SpinLock`** appears — the short-critical-section lock the primitives now share

Nearly 900 lines changed in `AsyncReaderWriterLock` alone.

## Memory

`TryCopyTo` on `ArrayPoolMemoryStream`, and a bounds-check fix in `ReadOnlySequenceMemoryStream`
(#126).

## Build

**The .NET Framework 4.6.2 build was fixed** (#118), and vulnerable transitive NuGet packages were
bumped (#123).
