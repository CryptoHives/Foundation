# CryptoHives Foundation 0.6.51

*Released 2026-07-30 · tag `0.6.51.25133`*

A BLAKE3 vectorization release, a new Memory primitive, and the benchmark infrastructure that the
0.6.79 dashboards are built on.

## Cryptography — BLAKE3 across four instruction sets (#203)

`Blake3State` was rebuilt to dispatch across:

| Path | Platform |
|---|---|
| `Blake3State.Avx512` | x86/x64, AVX-512 |
| `Blake3State.Avx2` | x86/x64, AVX2 |
| `Blake3State.Ssse3` | x86/x64, SSSE3 |
| `Blake3State.Neon` | Arm64 |

Over 2,800 lines changed across the BLAKE3 files. The XOF path (`Blake3State.Xof`) was vectorized
alongside the hash path rather than left on the scalar fallback.

AES transforms (`AesCipherTransform`, `AesCoreAesni`, `AesCoreArm`), `AesKeyWrapPad`, MD5 and
`HashAlgorithmPool` were all reworked in the same pass.

## Memory — `ISegmentOwner<T>` (#190)

Segment-ownership primitives, giving callers an explicit contract for who releases a pooled segment
and when — the missing piece for handing a `ReadOnlySequence<T>` across an API boundary without
guessing about lifetime.

## Documentation — porting guides

**`PORTING.md` for all three libraries** (#181) — `src/Memory`, `src/Threading` and
`src/Security/Cryptography` each gained a guide aimed at both humans and LLM agents migrating from
the BCL or from other libraries. These ship inside the packages.

## Benchmarks

**Benchmark results moved into a SQLite trends database with graphical trend display** (#205), and
a **threading dashboard** replaced the static tables (#206, #207). Benchmarks were re-run and
extended with macOS coverage (#204, #171). The short-lived Bencher CI integration was added (#146)
and then removed again (#193).

## Build and CI

- **Analyzer NuGet dependencies were wrong on .NET Framework** and were fixed (#209).
- Pipeline runs were reduced and the nuget-artifact pipeline's supply chain hardened (#188), Azure
  Pipelines runs trimmed with cancel-in-progress added (#187), workflow triggers scoped to relevant
  paths (#185), PR auto-labelling (#186), CODEOWNERS (#183), and PR/issue templates (#182).
