# CryptoHives Foundation 0.6.21

*Released 2026-07-04 · tag `0.6.21.58640` · **first stable release***

The first release without a `-preview` label. The headline feature is efficient timeout support, and
three genuine concurrency bugs were fixed on the way.

## Threading — timeouts (#163)

**`WaitAsync(TimeSpan timeout)` across the primitives**, implemented so that an uncontended or
untimed call costs nothing extra: a timer is allocated only when a caller actually passes a timeout
*and* has to wait. `TimeoutState<T>` carries the per-wait timeout state.

## Threading — concurrency fixes

- **A race condition that could deadlock on cancel** (#170).
- **A timer race that could cancel a *subsequent* wait** (#174) — a timer belonging to a completed
  wait could fire against the reused value-task source. Fixed by checking the `ValueTask` version
  before acting, which is exactly the protection the pooled-source design exists to provide.
- **A `WaiterQueue` race condition** (#167).
- **`TimeoutException` is now returned when the timer expires** (#172), rather than the wait
  completing as though it had succeeded.
- Flaky threading tests were stabilised (#175).

## Threading.Analyzers

- **New rule CHT009** — `SemaphoreSlim(1, 1)` used as an async lock, with a code fix migrating it to
  `AsyncLock` (#165). This is the analyzer's first "use this library instead" suggestion rather than
  a correctness rule.

> ⚠️ **Breaking change:** the analyzers were **removed from the `Threading` package** (#169).
> Diagnostics now require an explicit `PackageReference` to
> `CryptoHives.Foundation.Threading.Analyzers`. Projects that relied on the rules arriving
> automatically with the library will silently stop seeing them until the analyzer package is added.

## Cryptography

**Kalyna-512** (#159) completes the Kalyna block cipher set, plus a broad round of improvements
across the security library (#173).
