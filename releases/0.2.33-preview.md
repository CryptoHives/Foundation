# CryptoHives Foundation 0.2.33-preview

*Released 2025-12-09 · tag `0.2.33.45035-preview`*

A CI and analyzer-polish release.

- **CI build improvements** (#65), and NuGet packaging now builds Release packages only by default
  (#66) — Debug packages became opt-in via the `debugbuild` parameter, which is still how
  `azure-pipelines-nuget.yml` works.
- Analyzer diagnostic descriptors were reworded and the analyzer gained additional detection paths.
