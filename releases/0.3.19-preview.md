# CryptoHives Foundation 0.3.19-preview

*Released 2026-01-26 · tag `0.3.19.26783-preview`*

## New: `CryptoHives.Foundation.Security.Cryptography`

The fourth and largest package arrives (#70) — roughly 12,000 lines of self-contained managed
cryptography, with no OS or hardware dependency for correctness. Every type extends the
`System.Security.Cryptography` base classes, so they drop into existing code.

**Hash algorithms in this first cut:**

- **SHA-2 family** — SHA-224/256/384/512, SHA-512/224, SHA-512/256, over shared `SHA256Core` and
  `SHA512Core` compression cores
- **Keccak family** — SHA-3, SHAKE, cSHAKE and the `KeccakCore` permutation they share
- **KMAC** — KMAC128 and KMAC256
- **Ascon** (#86), added with a refactor of the test and benchmark registry that the rest of the
  package still uses to enumerate algorithms

Shared infrastructure — `BitOperations`, `MethodImplOptionsEx` — provides the polyfills that let one
implementation serve every target framework from .NET Framework 4.6.2 upward.

## Elsewhere

- The cryptography NuGet build was enabled (#89) and documentation prepared for the release (#91).
- Hash benchmarks gained result tables and a written discussion of what they show (#87, #88).
