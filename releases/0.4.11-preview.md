# CryptoHives Foundation 0.4.11-preview

*Released 2026-02-14 · tag `0.4.11.4957-preview`*

A performance and de-duplication release across both the cryptography and threading packages.

## Cryptography — new algorithms

- **Kupyna** (Ukrainian DSTU 7564:2014) (#104)
- **LSH** (Korean KS X 3262) — LSH-256 and LSH-512 (#105)

## Cryptography — performance

Measured improvements, each landing with the refactor that enabled it:

| Change | Effect |
|---|---|
| Ascon hash refactor (#94) | ~20% faster |
| SHA-2 compression loop (#93) | 10–20% faster |
| BLAKE2b, with AVX code factored out (#97) | ~5% faster |
| BLAKE3 for small buffers (#106) | faster short-input path |

Structural work underneath: `Sha2HashAlgorithm<T>` became a generic base for the SHA-2 variants,
the Keccak hash and XOF cores were merged to eliminate duplicated permutation code (#95), and KMAC
moved onto a shared `KeccakKMacCore` (#96).

## Cryptography — API

An XOF support interface (#100) and XOF benchmarks (#102), plus `ReadExactly` and a round of
guideline conformance (#99).

## Threading

**`WaiterQueue<T>`** (#103) — waiters now link into an intrusive doubly-linked queue instead of an
allocated collection, so a contended waiter costs no container allocation. Every primitive was
converted to it, and `AsyncBarrier` shed a third of its code in the process.
