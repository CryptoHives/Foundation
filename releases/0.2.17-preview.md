# CryptoHives Foundation 0.2.17-preview

*Released 2025-11-23 · tag `0.2.17.35073-preview`*

## Toolchain

- **Visual Studio 2026 and .NET 10 support** (#42). `targets.props` learned to select target
  frameworks per IDE version, which is still how the multi-targeting matrix works today.
- **.NET Framework 4.7.2 builds removed** from the library targets (#43). The cryptography package
  later reintroduced `net472` for its own use.

## Library

`AsyncLock` gained the bulk of the changes, alongside span-handling fixes in `ArrayPoolMemoryStream`
and `ReadOnlySequenceMemoryStream`.

## Documentation

Benchmark documentation was updated (#44) — the beginning of the benchmark-reporting effort that
grows through the 0.5 and 0.6 series into the interactive dashboards.
