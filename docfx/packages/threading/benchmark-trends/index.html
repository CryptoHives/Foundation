CryptoHives Threading Benchmark Trends

Benchmark history for CryptoHives.Foundation.Threading's async synchronization primitives — how each one performs against reference libraries (Nito.AsyncEx, NeoSmart, ProtoPromise, Microsoft.VisualStudio.Threading, and .NET's own built-in primitives) across platforms and contention levels, and how that's changed over time as the code evolves. Pick a platform, primitive family, and operation below; every implementation is plotted as its own line so they're directly comparable at a glance. Runs entirely in your browser (no server, no external database) — see the hint below the chart for the two view modes.

Data source: benchmark-history.sqlite, appended to by scripts/threading-benchmark-trends/record-benchmark-run.ps1 whenever someone decides a local run is worth keeping. Each point is one recorded run; hover a point for the exact commit and value. Trend over time plots every recorded contention level for the current filters at once (use the line-style legend below to hide levels you don't want). Scaling by contention plots contention level (queued waiters) on the X axis using each implementation's most recent run, showing how it scales under load at a glance. Some methods aren't contention-parameterized at all (e.g. a plain uncontended-only benchmark) — those show a single point per implementation in both views.
