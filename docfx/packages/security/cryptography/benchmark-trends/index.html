CryptoHives Benchmark Trends

Benchmark history for CryptoHives.Foundation.Security.Cryptography's hash, cipher, and MAC implementations — how each one performs against reference libraries (the OS, BouncyCastle, and others) across platforms and data sizes, and how that's changed over time as the code evolves. Pick a platform, category, algorithm family, and method below; every implementation is plotted as its own line so they're directly comparable at a glance. Runs entirely in your browser (no server, no external database) — see the hint below the chart for the two view modes.
