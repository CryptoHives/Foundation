CryptoHives Benchmark Trends

Benchmark history for CryptoHives.Foundation.Security.Cryptography's hash, cipher, and MAC implementations — how each one performs against reference libraries (the OS, BouncyCastle, and others) across platforms and data sizes, and how that's changed over time as the code evolves. Pick a platform, category, algorithm family, and method below; every implementation is plotted as its own line so they're directly comparable at a glance. Runs entirely in your browser (no server, no external database) — see the hint below the chart for the two view modes.

Data source: benchmark-history.sqlite, generated at build time by scripts/cryptography-benchmark-trends/import_run_archive.py from the run archive on the benchmarks branch — so it is a derived artifact rather than a committed file, and any recorded run can be rebuilt from the archive at any time. Table (one run) is the default: it reproduces one run's report, with the baseline row highlighted and Ratio computed against it per data size. Pick any recorded run rather than only the newest, and optionally a second one to compare against — two dates on one machine, or the same commit on two machines, which the run list marks as (same commit). The chart modes plot one point per recorded run; hover a point for the exact commit, value and the .NET runtime it was measured on. Trend over time plots every recorded data size for the current filters at once (use the line-style legend below to hide sizes you don't want). Scaling by size plots data size on the X axis using each implementation's most recent run, showing how it scales across sizes at a glance.
